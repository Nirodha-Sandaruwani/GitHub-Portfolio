# E15 Car Consumption Monitoring - Project Review

This is a complete summary of the E15: Car Consumption Monitoring App, a React 18 application using Redux and React Router. The app lets users create an account, log in, and track multiple cars’ fuel refueling events. Users can add refuel data (date, kilometers, liters, price), view a dashboard with total and average consumption, and visualize fuel costs using Recharts charts. Data is persisted to localStorage so it remains available between sessions, and the project is fully deployed on the JAMK student server.
