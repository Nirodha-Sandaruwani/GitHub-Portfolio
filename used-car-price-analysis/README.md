# US Used car

## Project topic 

Topic 1: Cars Dataset

Our group chose the US Used Cars Dataset for our project. The goal is to analyze what factors affect the price and sale time of used cars. We will explore how features like brand, model, year, mileage, and extra options (like Bluetooth or navigation) influence the selling price. Using data analysis and simple machine learning models, we aim to predict car prices and find which types of cars sell faster.
